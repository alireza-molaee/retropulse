# RetroPulse

ابزار فارسی برای اجرای جلسهٔ رتروسپکتیو از ثبت بازخورد تا تعیین اقدام.

## اجرا

با Node.js 24 یا بالاتر از پوشهٔ پروژه اجرا کنید. دستور اجرا ابتدا فرانت‌اند React را بسته‌بندی می‌کند.

```powershell
npm ci
npm start
```

[صفحهٔ اصلی](http://localhost:3000) را باز کنید یا مستقیم به [ساخت جلسه](http://localhost:3000/create) بروید. برای امتحان کردن نقش مهمان، لینک دعوت را در یک پنجرهٔ خصوصی باز کنید. پیش‌فرض سرور فقط روی دستگاه محلی در دسترس است. داده‌ها در `data/retro.sqlite` ذخیره می‌شوند.

```powershell
npm test
```

## امکانات

میزبان یک برد می‌سازد و اعضا با لینک دعوت و آواتار وارد می‌شوند. جلسه پنج مرحله دارد: نوشتن، گروه‌بندی، رأی‌گیری، اقدام‌ها و پایان. کارت و کامنت می‌توانند ناشناس باشند. تایمر، وضعیت آمادگی، واکنش‌ها و نظرسنجی اختیاری بین اعضا همگام می‌شوند. در پایان، اعضا گزارش جلسه را برای Confluence کپی می‌کنند.

## اجرای نسخهٔ ساخته‌شده

برای استقرار کانتینری، [راهنمای Docker و HTTPS](docs/deploy-docker.md) را ببینید.

از ریشهٔ پروژه `npm ci` و سپس `npm run build` را اجرا کنید. برای اجرای خروجی ساخته‌شده از `node server.js` استفاده کنید. متغیرهای محیطی `HOST` و `PORT` نشانی و پورت سرویس را تعیین می‌کنند. سرویس را به‌صورت یک فرایند اجرا کنید و برای پوشهٔ `data` فضای پایدار در نظر بگیرید. برای گرفتن نسخهٔ پشتیبان فایل SQLite، ابتدا سرویس را متوقف کنید.

آزمون مرورگر با `npm run test:browser` اجرا می‌شود و به Microsoft Edge نصب‌شده نیاز دارد. هر دو مجموعهٔ آزمون از برد آزمایشی مجزا استفاده می‌کنند.

[راهنمای سبک و دیزاین سیستم](docs/style-guide.md) رنگ‌ها، کامپوننت‌ها و الگوهای برد را توضیح می‌دهد.
